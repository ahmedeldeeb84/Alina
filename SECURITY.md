# Security policy

ALINA may process confidential workplace narratives. Please avoid filing public GitHub issues containing company-confidential, employee-sensitive, or personal information.

## Reporting a vulnerability

Use GitHub's private security advisory mechanism when available. Do not publish credentials, private narratives, or exploit details in a public issue.

## Secrets

ALINA reads provider credentials from environment variables and does not persist them. Never commit `.env` files or API keys.
