# Release checklist

- [ ] `pytest` passes.
- [ ] CLI smoke test passes from an installed wheel.
- [ ] `DESIGN.md` still matches implemented behavior.
- [ ] No private or employer-confidential narrative is committed.
- [ ] No API keys / `.env` files are committed.
- [ ] Offline mode makes zero network requests.
- [ ] Cloud-provider privacy warning is present.
- [ ] Reality-check fixtures include alternative hypotheses.
- [ ] High-stakes fixtures include human-support cautions.
- [ ] GitHub Actions workflows are valid.
- [ ] CHANGELOG version matches package version.
