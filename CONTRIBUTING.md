# Contributing

Contributions are welcome, especially improvements to epistemic discipline, privacy, evaluation fixtures, provider adapters, and transparent pattern detection.

1. Create a focused branch.
2. Add or update tests.
3. Preserve the distinction between facts, assumptions, and unknowns.
4. Do not add employee scoring, protected-trait inference, covert monitoring, retaliation, or manipulative guidance.
5. Run `pytest`.
6. Explain behavioral changes in the pull request.

Please use synthetic examples in tests and documentation. Do not contribute real confidential workplace narratives.
